# Stavka

Native Arma Reforger protocol-v1 bridge. Open `addon.gproj` in matching
Arma Reforger Tools (currently 1.8.0.13).

Setup, packaging, configuration and acceptance:
[docs/arma/README.md](../../docs/arma/README.md).

The bridge is disabled until the authority's external `$profile:stavka.json`
is configured. Never put credentials in this addon directory.
